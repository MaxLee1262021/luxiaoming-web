# 照片留影商品配置

后台「照片留影」的新增与编辑统一维护小程序商品内容。

1. 填写商品名称，选择已有风格系列（如古风汉服、清新夏日）或输入新风格。标签可选主推、爆款、新品及历史标签，也可自定义；保存后都可在其他商品中复用。
2. 点击照片区域的「＋」一次选择多张照片，或点击「上传文件夹」导入文件夹中的图片。照片在同一行按顺序展示，较多时可横向滚动；页面自动统计上传张数。
3. 首张自动作为首图，也可在任意照片下点击「设为首图」。首图用于小程序照片留影商品卡片；可替换、单张删除，或勾选多张后批量删除，删除首图后由剩余照片补位。
4. 设置唯一价格、修图方式（按张数 / 包含 / 不包含）及是否含妆造。照片张数由上传的商品照片自动统计，无须手填。拍摄说明可使用默认模板后继续修改。
5. 按需开启小程序显示、关联一个打卡点；新商品默认隐藏且不关联打卡点，选择风格系列不会自动绑定打卡点。
6. 点击「保存确定」后回到照片留影商品列表。支持卡片与列表两种展示，显示名称、风格、标签、照片与修图张数、妆造、价格、关联打卡点及显示状态，并提供编辑、显示设置、关联、标签和删除操作。

编辑页所有字段和开关统一保存后生效；取消或还原可丢弃未保存修改。上传过程中禁止保存、退出及删除，避免遗漏尚未完成的图片。小程序详情顶部显示照片张数、修图和妆造，风格系列及商品标签分别展示。

关联打卡点隐藏或商品售卖关闭时，商品仍会按现有可见性规则隐藏；这些兼容设置在编辑页「其他设置」中维护。

## 数据字段

| 配置 | 字段 |
| --- | --- |
| 名称 | `name` |
| 风格系列 | `seriesId` / `seriesName` |
| 商品标签 | `tags` |
| 商品照片、首图 | `sampleUrls`、`cover` |
| 拍摄说明 | `shootingNotes`，同步兼容 `intro` |
| 唯一价格 | `price` |
| 商品照片张数（按上传图片自动统计） | `photoCount` |
| 修图 | `retouchMode`（`count` / `included` / `excluded`）、`retouchCount` |
| 妆造 | `makeupIncluded` |
| 可选打卡点 | `spotId` / `spotIds`，`spotBindingExplicit` 保留显式不关联 |
| 小程序显示 | `isShow` |

`sampleUrls` 一旦配置即为商品图片来源，包括空数组；历史独立素材只在未配置该字段时兼容读取，删除的图片不会被重新归集。历史未设置修图方式的商品按修图张数兼容显示。

## 发布说明

本次创建流程复用现有照片商品字段，更新了后台与 API；小程序继续读取 `cover`、`sampleUrls`、`photoCount` 及服务字段。代码验证使用隔离测试数据，未操作真实数据库。

正式部署时发布后台与 API。若部署环境尚未包含现有照片商品字段，按原有数据库备份与迁移流程补齐。小程序真机展示及真实文件上传需在部署环境复核。
