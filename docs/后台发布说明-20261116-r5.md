# 后台发布说明：2026-11-16 r5

发布包：`luxiaoming-admin-linux-20261116-updater-r5.tar.gz`，由当前正式后台工作区生成。

## 本次标签调整

- 照片留影、视频摄像、旅拍套餐的标签字段均为必填，三个编辑器显示必填标记，并在保存前校验。
- 服务端同时校验创建、编辑及重新上架请求。关联拍摄风格、旧服务标签不能代替商品标签，空数组、空白或无效值不能通过校验。
- 存量无标签商品仍可直接下架或隐藏；同时修改名称、价格等内容时必须先补标签。
- 公共商品接口独立保留商品标签 `tags` 与服务描述 `serviceTags`，修复后台新标签被空数组或旧服务描述覆盖的问题。

小程序对应改动位于独立的小程序源码目录：三类商品卡片封面显示后台配置标签，视频和套餐的封面起价角标已替换，正常价格保留。多标签在封面展示首个标签与其余数量，正文保留完整列表，避免超出封面而被裁切。后台包不包含小程序，需重新编译或发布小程序后配套生效。

本次标签调整没有新增数据库结构变更，不需要额外数据迁移，也不会自动补造存量商品标签。需要维护的商品应在后台填写实际标签并保存。

## 打包与验证

发布前执行 `npm run check`、`npm run build`、`npm test`，并验证三个 Linux 部署脚本语法。归档核对 SHA256、单一顶层目录、源码一致性、部署脚本 LF/0755，以及更新脚本和 helper 配对。

默认包不包含 `.env`、数据库、依赖目录、测试目录和密钥；服务器现有配置由更新器保留。
