# 套餐周边库存与物流

套餐详情展示周边商品参考单价。含周边的套餐预约必须选择本人保存的收货地址；商品与地址从服务端目录生成快照，客户端不能修改套餐内商品、数量或金额。

库存与履约规则：

- 支付前预占现有实物 SKU 库存，与周边独立购买共用库存。数量为套餐购买数量乘以每份包含数量，相同规格合并。
- 定金未付清套餐总款时只预占；款项全部确认到账后扣减库存，生成一个待发货实物子单。百分之百定金的套餐在定金到账后达到付清条件。
- 子单金额已包含在套餐中，不独立收款，不重复统计销售收入；售后退款由套餐订单处理。
- 客服在现有实物订单管理中发货，复用快递轨迹、微信发货同步和确认收货。服务订单详情可进入对应实物订单。
- 取消未发货套餐会释放预占或回补已扣库存；已经发货的订单冻结核实，不能直接回补。重复支付回调、重试、恢复任务均不会重复扣减。
- 无支付流水且超过三十分钟的未支付预约通过比较更新作废后释放库存；仍存在待确认微信交易时保留预占，由查询或取消流程核实交易。
- 多规格商品必须在套餐配置中指定规格；缺库存、关联商品或有效地址时阻止创建可付款交易。

发布需同步更新小程序和后台服务。复用既有实物交易表，未新增数据库表；环境仍需已完成原有实物交易迁移和物流配置。

本次处理适用于更新后新建并保存履约快照的套餐预约。历史订单及历史未支付预约没有可靠商品和收货地址快照，不自动按当前套餐内容补扣库存或补建子单。
