# 四模块视觉改版与小程序展示补齐

完成日期：2026-11-02。

## 改动内容

后台照片留影、视频摄像、旅拍套餐、影像周边统一为紫色卡片列表、分区编辑表单及右侧实时预览。四模块使用独立草稿，保留正式保存、上传、权限、回收站和关联可见性规则。保留照片交付张数和修图方式、视频时长/成片数量/交付周期、套餐每项数量/售价/定金等字段。

- 照片：首图与预览图管理、风格与标签、拍摄说明、单一价格、交付照片张数、三种修图方式、妆造。
- 视频：商品视频/封面/附加素材、标签、时长、成片数量、交付周期、航拍/剪辑/妆造、拍摄说明。
- 套餐：三类组合商品按点位筛选，切换筛选保留已选内容；单价乘数量计算原价；手动售价和定金配置保留；标签和服务内容分别保存。
- 周边：规格数组、共享标签、图视频素材、产品说明、交付周期、精修/精剪；旧小店参数进入高级设置。

说明、主图、规格、标签采用现有正式字段并兼容历史别名。明确清空说明或主图时同步清空旧别名，避免旧内容重新出现。历史媒体对象按 url/src 等真实地址读取，不转换为对象字符串。

后台共用新增文件为 src/views/content/album/catalog.css，四模块 CSS 通过 @import 引用，交付时应保留该文件。

## 小程序展示

小程序沿用现有暖色品牌和基础组件：

| 页面 | 已补内容 |
| --- | --- |
| 视频详情及卡片 | 商品真实拍摄说明、全部标签、妆造；时长带秒单位、成片数量带条单位；商品附图与视频按媒体类型预览 |
| 套餐详情及卡片 | quantity/qty、总件数、类型数、每项数量、套餐说明、服务标签；标签和说明可换行 |
| 周边展示 | 随选中商品更新分类、真实配置售价、标签、完整规格、产品说明、交付周期、显式精修/精剪、图视频图库 |
| 订单详情 | 已有 productItems 的名称、类型、数量和已记录单价；不以现有商品资料推断历史订单内容 |

卡片文字改为正常文档排版和自动高度，长标题、标签、价格、说明及长英文可换行；窄屏组合行和金额区域可换行，保留固定底栏安全空间。周边仍使用展示和咨询流程；缺售价时不伪造零元，网络失败使用预览内容时显示预览标识。

本阶段保留现有单商品可选单点规则，未开放多点单商品、实物购买/库存扣减、支付物流或套餐订单子项快照。
