## 一、设计原则（Design Principles）

1. **品牌即信任**：暖胶片国风不可丢，鹿印是最高频视觉锚点；后台也要"有氛围感但不端着"。
2. **一致性 > 个性**：同类型页面同结构、同组件、同间距；宁可不惊艳，不可碎片化。
3. **密度适中**：后台是生产力工具，信息密度高于 C 端，但仍用留白与分区避免"Excel 冷感"。
4. **可访问性内建**：WCAG AA（正文 4.5:1、大字 3:1、触控 ≥44px、键盘可达）从令牌起就满足。
5. **角色即视线**：不同人进后台看到的是"不同的世界"，不是同一界面打权限补丁。
6. **设计可解耦**：所有视觉走 `--lxm-*` 令牌；改品牌只动 tokens.css，不动 2000 行业务样式。

## 二、设计令牌体系（正式化为唯一标准，并补完）

### 2.1 颜色（已存在，照单全收，对比度已核）

- **品牌主色**：`--lxm-brand #D9531E`（链接/激活/强调，AA 安全 burnt orange）
- **品牌活力**：`--lxm-brand-vivid #FF8D52`（装饰填充/图表/hover 光晕）
- **品牌红**：`--lxm-brand-strong #EE2C2C`（主按钮实底 + 危险/紧急，白字 4.57:1 ✓AA）
- **品牌深**：`--lxm-brand-deep #B8430F`（主按钮 hover/active）
- **墨**：`--lxm-ink #2A211B`（侧栏底/大标题）、`--lxm-cream #FFF7EF`（奶油浅底）
- **语义**：success `#1F9254` / warning `#B7791F` / danger `#EE2C2C` / info `#2F6FB0`（均带 soft 底）
- **中性（暖化）**：bg `#FAF7F3`、surface `#FFFFFF`、ink-2 `#4A3F38`、muted `#7C6A5E`、line `#EFE6DD`
- **Element Plus**：`--el-color-*` 已全部重定向到品牌（主橙、成功绿、警告棕、危险红、信息蓝）

### 2.2 字体（**本次补完**）

- **界面中文**：`"PingFang SC", "Microsoft YaHei", system-ui`（无衬线，清晰优先）
- **界面英文/数字**：`Inter, system-ui`
- **金额/编号/工单号**：等宽 `"JetBrains Mono", ui-monospace`（对齐可读，金额不错位）
- **字阶（已定义）**：xs12 / sm13 / base14 / md15 / lg18 / xl20 / 2xl24 / 3xl30
- **字重**：常规 400、中 500（按钮/标签）、 semibold 600（标题）、bold 700（数字强调）
- **行高**：标题 1.3、正文 1.6、表格 1.5
- **规则**：后台正文固定 14px（base），不缩放；金额/状态用 600/700 拉开层级

### 2.3 间距 / 圆角 / 阴影 / 层级 / 动效（已定义，列清用法）

- **间距（4px 基数）**：1=4 / 2=8 / 3=12 / 4=16 / 5=20 / 6=24 / 8=32 / 10=40 / 12=48
  - 用法：页内边距 24、卡间距 16、表单行距 20、区块间距 32、分区间距 48
- **圆角**：sm6（标签/输入框）/ md10（卡片/弹窗）/ lg14（大卡）/ xl20（浮层）/ pill（徽章）
- **阴影（暖墨投影）**：sm(列表 hover) / md(卡片/弹窗) / lg(抽屉/气泡)
- **层级 z-index（本次补完）**：`--lxm-z-nav 100 / filter 200 / drawer 1000 / modal 1100 / toast 1200 / tooltip 1300`
- **动效**：`--lxm-ease cubic-bezier(.4,0,.2,1)`；fast 120ms / normal 240ms；**尊重 `prefers-reduced-motion`**，关闭位移与淡入

## 三、视觉语言落地规范

- **主按钮**：品牌红实底 + 白字，hover 转 `--lxm-brand-deep` 并上移 1px + md 阴影；圆角 md10。
- **次按钮**：描边 `--lxm-brand`，文字品牌橙；hover 浅橙底。
- **侧栏**：焦糖墨底 `#2A211B`，顶部鹿印 logo + 项目名；激活项左侧 3px 品牌红 + 浅橙底。
- **数据强调**：金额用等宽 + 600；正向绿、负向红、待处理橙、信息蓝，统一 semantic soft 底徽章。
- **空/加载/错误态**：全站统一三件套（鹿印空态插画 + 一句引导 + 主操作；骨架屏；错误卡 + 重试）。

## 四、信息架构与导航（对齐商业铁律重排）

### 4.1 必须修的两处冲突（商业铁律）

1. **`videoProducts 短视频套餐` 应并入「旅拍套餐」**：铁律规定全站只留**一个旅拍套餐**，可把照片单品/短视频单品/周边任意组合 + 组合价；**删除独立"短视频套餐"概念**。导航上"视频摄像"作为商品种类②（短视频单品）保留，但"短视频套餐"入口撤销，组合能力收到"旅拍套餐"内。
2. **`samples` 孤儿集合**：导航里 `['spots','samples'].includes` 仍引用 `samples`，但小程序不消费该集合（记忆已确认）。**从导航移除**，避免运营误入空页。

### 4.2 建议导航树（角色分区，配置驱动）

```
概览
├─ 运营驾驶舱（dashboard / performance / trace）

├─ 照片留影（albums）            ← 商品种类①
├─ 视频摄像（videoSingle）       ← 商品种类②（短视频单品）
├─ 旅拍套餐（packages）          ← 商品种类③（吸收原 videoProducts，支持多选基础商品组合+组合价）
```

## 五、应用框架布局（App Shell）

```
┌──────────────┬──────────────────────────────────────────────┐
│  侧栏 240px   │  顶栏 56px：面包屑 · 全局搜索 · 角色切换 · 通知  │
│ （焦糖墨底）   ├──────────────────────────────────────────────┤
│  鹿印 logo     │                                              │
│  导航分区      │   内容区（max 1280，padding 24）              │
│  激活态红条    │   筛选栏 → 数据表格 / 看板 / 表单             │
│  收起 64px     │                                              │
└──────────────┴──────────────────────────────────────────────┘
```

- **侧栏**：展开 240 / 收起 64（迷你字锚点）；底部署名"鹿小鸣 · 旅拍后台"。
- **顶栏**：左面包包屑（模块 / 页），中间全局搜索（订单号/商家/分销员），右侧角色切换 + 通知铃 + 当前操作员。
- **内容区**：标准底色 `--lxm-bg`，卡片表面 `--lxm-surface`，统一圆角 md10 + sm 阴影。
- **断点**：桌面 ≥1024 完整；平板 768–1023 侧栏自动收起；手机 <768 见第九节。

## 七、页面模板（5 类标准，复制即用）

1. **L 列表+筛选**：筛选栏 + 指标卡（可选）+ 数据表格 + 分页 + 行操作（查看/编辑/上架）。
2. **D 详情抽屉**：头部摘要（状态徽章+关键金额）+ 标签页（基本信息/分账/时间线/售后）+ 底部操作。
3. **F 表单向导**：分步或单页表单，必填校验，底部 `存草稿-提交`；复杂用步骤条。
4. **B 数据看板**：指标卡网格 + 图表（橙系配色）+ 趋势表；首屏不加筛选。
5. **R 对账/财务**：多 Tab（按商家/分销员/摄影师/总部）+ 分账切片表 + 导出（带比例字段）。

## 九、响应式与移动后台

- **桌面（≥1024）**：完整三栏，主战场。
- **平板（768–1023）**：侧栏自动收起为 64px 迷你字；表格横向滚动保留关键列。
- **手机（<768）**：不做"完整后台缩排"——改做**独立轻后台**（分销员/商家各一个 PWA 风格单页）：只保留其视线地图里的模块，底部 Tab 切换，触控 ≥44px，列表卡片化（非表格）。与小程序同源品牌，复用 `--lxm-*` 令牌。

## 十、可访问性（WCAG AA）

- 颜色对比：正文 `--lxm-ink-2 #4A3F38` 落 `--lxm-bg` 达标；品牌红白字 4.57:1 ✓。
- 键盘：所有可操作元素可达，焦点环 `2px 品牌红 + 2px offset`；Tab 顺序=视觉顺序。
- 语义：表格用 `el-table` 已带 role；弹窗 `aria-modal`；图标按钮带 `title`/`aria-label`。
- 触控：按钮/标签最小 44×44。
- 动效：`@media (prefers-reduced-motion: reduce)` 关闭位移与淡入，仅留颜色切换。

## 十一、设计交付与 QA

- **交付物**：本方案 + 组件规范 + 5 类页面模板 + 令牌表（已具）。
- **标注**：所有尺寸/色值/状态写死在规范，开发者按令牌实现，不靠截图猜。
- **QA 门禁**：① 全站色值 100% 走 `--lxm-*`（grep 无 `#` 硬编码除外边框）；② 同类型页结构一致；③ 角色视线无越权；④ 触控 ≥44px；⑤ 键盘走查通过。
- **流程**：设计改 tokens.css → 开发者按模板实现 → 设计抽页走查 → 回归对比。
