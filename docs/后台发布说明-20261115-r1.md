# 后台发布说明 2026-11-15 r1

发布包：`luxiaoming-admin-linux-20261115-updater-r1.tar.gz`。由当前正式后台工作区生成的 Linux 源码部署包，包含实物交易功能及当前工作区的账号、菜单、权限与更新器改动。

## 本次功能

- 周边独立购买、多商品一笔全款订单、购物车、地址簿及交易库存；小程序需配套发布对应新版。
- 客服工作台“实物订单”，无需领取，必选快递公司并填写物流单号；确认成功自动记录实际发货处理人，再交承运商。
- 实物全款与服务定金/尾款独立分流，按商品售后/退款、证据文件归属验证、未付款改址安全关单、库存调整与旧预约周边加购保护。
- 快递100订阅、可信回调、运单版本隔离、限频查询、异常重试；适用账号微信发货和统一收货核实。

详见 [开发与部署说明](周边商品交易开发与部署-20261115.md)、[物流接入说明](快递100与微信实物物流接入-20261115.md) 和 [无密钥配置模板](physical-commerce.env.example)。

## 数据库与配置

此会话对应的服务器已于 2026-11-15 完成实物专项建表，12 张 `lxm_physical_*` 表及事务锁已核验，原有 134 张业务表结构和数据摘要未变化；无需因上传本包再执行一遍迁移。

其他环境若尚未建表，在完成可恢复备份和目标库核对后单独执行：

```bash
npm run migrate:physical-commerce -- --apply --backup-confirmed
```

该专项不由普通更新器的 `--migrate` 代替，也不需要为此运行原服务订单数据迁移。本次包发布时沿用服务器 `.env` 及支付/OSS配置；快递100 Key、Customer、HTTPS 回调已在对应服务器准备，仍需新代码上线后的真实联调。

实物购买总开关默认关闭，商品不会自动开售。部署后在“客服工作台 → 实物订单 → 销售配置”核对可售现货、库存、运费、省份、支付时限和售后参数；适用的微信发货管理同时核对服务器开关、承运商映射及后台收货开关。完成实际支付、退款、物流及收货验证后再开放销售。
