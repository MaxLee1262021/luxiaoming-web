# 后台发布说明 2026-11-12 r1

发布包：`luxiaoming-admin-linux-20261112-updater-r1.tar.gz`。由当前
`luxiaoming-admin-交付包` 工作区生成，包含之前的后台功能及本轮页面加载修复、首屏性能优化。

## 页面加载与首屏

- 页面资源按实际访问加载，成功后复用；请求超过 10 秒自动重试一次。
  重试使用独立请求 URL，避免浏览器复用仍挂起的脚本下载；失败节点会清理，
  连续失败显示“重新加载”，其他菜单仍可使用。
- 入口脚本通过 `defer` 并行下载并保持执行顺序；提前预加载登录页面资源。
  框架下载期间显示加载状态，登录前不编译完整后台与业务弹窗模板。
- 使用同版本 Vue 3.5.39 官方完整生产构建，保留运行时模板编译功能。
  来源、归档完整性和文件 SHA256 见 `public/vendor/SOURCES.md`。
- 公共静态文本支持 gzip、ETag、Last-Modified 和 304 校验。
  非哈希文件每次重载都重新验证，发布更新不会依赖长时间缓存过期。
  压缩缓存有容量限制；API、运行时配置和业务数据不进入静态文件缓存。

隔离测试环境中，在 80 ms 网络延迟、768 KiB/s 下载限速、4 倍 CPU 限速且禁用浏览器缓存的
同条件下，各测 3 次取中位数：登录可操作时间从 5.92 秒降至 1.80 秒，
资源传输量从 3.16 MB 降至 0.69 MB。此结果用于优化前后对比，不代表生产环境时延保证。
登录界面截图保持一致；浏览器验证覆盖请求挂起恢复、登录、修改密码弹窗、会话恢复、
退出重登及会话过期。

## 上传与更新

默认发布包不含 `.env`、Windows 依赖目录、数据库数据、上传物或本机密钥。
使用服务器现有配置和证书。上传归档及 SHA256 文件后执行：

```bash
cd /tmp
sha256sum -c luxiaoming-admin-linux-20261112-updater-r1.tar.gz.sha256
sudo bash /opt/luxiaoming-admin/deploy/linux/update.sh /tmp/luxiaoming-admin-linux-20261112-updater-r1.tar.gz
```

本轮加载优化不新增数据库结构，无需为此追加 `--migrate`。
如果服务器尚未安装之前的客服或摄影师分成模块，仍需按对应文档单独完成所需迁移；
更新器的通用迁移不能代替业务迁移。本次打包不执行服务器部署或数据库迁移。

## 验证与回退

交付前执行 `npm run check`、`npm run build`、完整 `npm test` 及部署脚本语法检查，
并验证单一归档根目录、当前代码一致性、排除项、部署脚本 LF/0755 和 SHA256。
具体测试统计与归档大小随打包结果提供。

更新器保留服务器配置和旧代码，并检查 `/api/health`；没有数据库结构迁移的代码更新
失败时，按更新器约定尝试恢复旧代码。历史业务数据迁移或财务清理仍使用各自备份流程。
