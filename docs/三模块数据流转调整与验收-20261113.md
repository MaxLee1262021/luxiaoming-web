## 实现变更

### 客服工作台

- 首次登记摄影师只允许 `confirmed`；认领、确认时间、派单、开始拍摄、完成保持独立操作。转派继续允许进行中订单，目标必须在职。前端入口、提交校验与服务端前置状态一致。
- 工作台待办依次处理紧急预占、公共池前六笔、待复核客诉及履约阶段。公共单可直接认领，已完成订单的客诉待办进入复核，不再显示拍摄跟进。
- 状态停留时间从持久化操作流水推导；确认原预约时间也记录确认操作。回流次数从预占终态记录推导，超时与主动放弃保留幂等审计。
- 预占退款清除订单上的预占客服并关闭预占记录，不回流、不解绑；预占记录保留用于审计。原有静默起算和其他预占单存在时不解绑的规则继续生效。
- 优化后的 SQL 只读查询同步加载必要的操作流水、客诉及预占历史，避免完整读与优化读得到不同结果。
- 重复客诉只提交一次；收到 `4010` 后定位已有客诉及订单记录。

旧单没有历史操作流水时，停留时间回退到已有状态时间、完成时间或支付时间，不补造历史事件。

### 客服分成

- 已确认账单保持原金额。改判撤销冲抵时追加金额为零的 `cancel_offset` 记录，未执行部分取消，实际已扣部分生成补发。
- 完全执行过的计划也保留取消终结标记，避免重试重复补发；后续再次判责可建立新的计划。
- 观察期内恢复保持原观察到期时间，不增加财务调账；可结算的恢复保留恢复记录。
- 客服结算、补发和查询试算明确排除 `photo:` 调账，防止摄影师资金进入客服结算。
- “我的分成”展示本月未结预估、观察中待确认笔数及金额、本期冲抵、补发及待扣余额，可展开查看订单、原因、金额和时间。未确认金额通过私有快照试算，不写回账本；确认后读取账单快照。

### 摄影师分成及跨模块联动

- 客服新派单、转派和旧订单 SQL 桥接均校验目标摄影师 `active`。转派保留原人零元明细、新人按自身支付时比例计酬，并追加摄影师档案留痕。
- 摄影师责任改判为其他责任时，工作台同时触发摄影师恢复。未结明细按原金额和比例快照恢复；已推送单据及其明细保持冻结。
- 已推送后的未执行扣回可撤销；已实际扣回金额生成一次 `photo:` 补发计划。草稿预留金额不作为已扣款，不生成虚假补发。
- 补发可在无新完成订单时单独生成下一期草稿。沿用现有有符号金额字段，负 `offset_fen` 表示净补发，页面明确标注。
- 明细及 CSV 显示待调账/待补发原因，页面保留原账单状态并展示后续调整。
- 终止合作实时拦截继续保留，`4302` 附在途笔数与列表。“去处置”进入按摄影师筛选的客服跟进页，按原客服/主管权限处理，不再跳入只读订单流水页。
