# 摄影师账号同步创建

新增摄影师统一使用“摄影师分成管理 → 摄影师列表 → 新增摄影师”。“摄影师账号”区域参照客服新增，提供“新建登录账号”和“关联已有账号”两种方式，默认新建。新建时由管理员填写登录账号和登录密码；关联时填写已新增的摄影师登录账号，无需填写密码，继续使用原密码登录。切换方式会清除已输入的密码。PH 编号仍由系统生成，档案、初始比例、建档日志及账号创建或关联在同一事务中提交，账号冲突或任一写入失败均整体回滚。

关联账号须已启用，且角色为已启用的摄影师，尚未绑定其他摄影师档案或客服等其他业务身份。历史普通人员入口生成、角色为摄影师的账号可通过此处补齐 PH 绑定；后续在旧人员管理中编辑资料、启停或重置密码时保留该绑定。账号原密码、角色及权限保持原值，不自动为其他角色账号改角色；角色不符时先在权限管理核对。账号和本人档案使用相同手机号可正常关联，其他人员或档案的手机号冲突仍会阻止保存。保存成功后自动关闭弹窗并刷新摄影师列表。

合作协议编号在保存时自动生成，格式为 `PH-XY-YYYY-NNNN`（年份及四位年度流水号，例如 `PH-XY-2026-0001`），跳过已有协议编号。新增页面只显示“保存后自动生成”，不再要求手填；保存后的实际编号在摄影师列表与详情中查看，历史协议编号保持原值。

“结算方式”使用下拉选择：日结、周结、月结，默认月结。所选方式与档案一起保存，并在列表及详情中显示；保存失败保留选择，取消或重新进入新增页恢复默认月结。旧档案未填写结算方式时按月结展示。此次修改为档案配置，不改变已有的按完成月份归集对账和线下登记发放流程。

登录账号去除首尾空白、最多 128 个字符，不允许控制字符或平台保留的 admin 账号；新建时登录密码须为 8–128 位，包含字母和数字，按原样处理。数据库只保存密码哈希，建档响应、档案、日志、查询和导出均不包含密码。该账号可在“权限管理 → 人员”中查看，摄影师使用新建时填写的密码或已有账号原密码登录后只可查看和导出本人分成，后续密码重设仍通过权限管理进行。

保存成功后返回摄影师列表并清除表单密码，不再弹出自动生成密码。校验或保存失败保留表单，便于修改重试；重置、取消、离开页面及切换登录账号会清除输入的密码。登录信息由管理员按既有安全渠道交付摄影师。

旧“人员账号管理”与“权限管理 → 新增人员”原先能选择摄影师角色，但仅生成普通人员身份，缺少 PH 档案绑定，无法通过摄影师登录校验。现在这些新增入口引导到专用建档页；直接调用旧新增 API 也会返回 `409 / PHOTO_PROFILE_REQUIRED` 和目标路由 `photoNew`，不会写入半成品人员或账号。已有人员和账号的正常编辑、启停及密码重设保留；历史账号通过新增弹窗显式选择关联，不会自动迁移或重绑。

本次不新增数据库结构，也不创建真实测试摄影师。测试使用隔离 SQL/账号数据验证原子创建、失败回滚、旧入口拦截、系统账号列表、本人登录和权限范围。
