# 拍摄完成与尾款支付

客服或摄影师登记拍摄完成后，订单进入待付尾款；尾款经服务端确认到账后，订单才最终完成。

| 操作或结果 | 后台客服状态 | 小程序展示与操作 |
| --- | --- | --- |
| 开始拍摄 | `shooting` | 拍摄中，尚不能付尾款 |
| 登记拍摄完成 | `final_pending` | 归入“拍摄中”，详情显示拍摄已完成及支付尾款入口 |
| 发起或取消微信支付 | `final_pending` | 等待实际支付结果，不能在本地标记完成 |
| 服务端确认尾款到账 | `done` | 已完成，不能重复付款 |
| 尾款为零 | `final_pending` | 顾客点击“确认完成订单”，经服务端确认后变为已完成，不调起微信支付 |

内部工作流使用 `awaiting_final_payment`，客服状态列保存 `final_pending`，兼容现有字段长度。拍摄完成时间与订单完成时间分别保存；本次完成的客户绑定、保护期续期及分成观察期在最终完成时处理。重复完成登记、支付回调及零尾款确认保持幂等。

取消、退款、付款待核验及售后限制继续由服务端校验。已有历史完成订单不自动改为待付款，也不根据缺失的历史凭证重新收款；历史差异需核对实际收款记录。

联动回归见 `server/tests/customer-service-order-sync.test.cjs`、`server/tests/svc-final-payment-flow.test.cjs`、`server/tests/wechat-pay.test.cjs`，小程序支付交互见小程序项目的 `tools/test-final-payment-flow.cjs`。部署后台和发布小程序后，新流程生效。
