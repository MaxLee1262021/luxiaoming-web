# 后台发布说明 2026-11-11 r1

发布包：`luxiaoming-admin-linux-20261111-updater-r1.tar.gz`。本包由当前工作区生成，包含客服工作台、客服与摄影师分成，以及本轮后台查询响应优化。

## 本轮优化

结构检查、模块集合、权限人员与关联数据改为批量读取。客服及摄影师分成按查询所需依赖读取，写入事务、账单快照及授权实时校验保留。MySQL 默认协商协议压缩，大型成功 GET JSON 按客户端能力使用 gzip。

当前环境只读采样覆盖 61 个查询入口、300 次成功请求，均低于一秒，整体 P95 为 412ms。此结果基于当前数据库与网络，并非生产高并发或大订单量保证。实现及验证范围见[后台查询性能优化](后台查询性能优化-20261111.md)。

## 更新

此源码包不含 `.env`、依赖目录、数据库数据、上传物、测试数据、数据库备份或本机密钥。使用服务器现有 `.env`、证书和配置。先上传归档及同名 SHA256 文件到 `/tmp`，然后执行：

```bash
cd /tmp
sha256sum -c luxiaoming-admin-linux-20261111-updater-r1.tar.gz.sha256
sudo bash /opt/luxiaoming-admin/deploy/linux/update.sh /tmp/luxiaoming-admin-linux-20261111-updater-r1.tar.gz
```

本轮接口优化不需要新增 SQL。若目标环境尚未安装客服/摄影师分成，按对应文档单独执行业务迁移；更新器的 `--migrate` 只处理通用 MySQL 迁移，不能代替分成模块迁移。本次打包不执行数据库迁移、存量清理、服务器部署或真实外部服务调用。

`DB_COMPRESS` 默认启用；服务器不支持时协议自动协商关闭。如需排查兼容问题，可在服务器 `.env` 设置 `DB_COMPRESS=false` 后重启。保持 `DB_AUTO_MIGRATE=false`。

摄影师存量财务清理有独立的快照、校验和恢复流程，不随代码更新自动触发，见[摄影师分成存量清理](摄影师分成存量清理-20261111.md)。
