发布包：`luxiaoming-admin-linux-20261113-updater-r1.tar.gz`，由当前 `luxiaoming-admin-交付包` 工作区生成，包含之前功能及本轮客服调整。

- 新增客服时可直接填写登录账号和初始密码，同一事务创建账号、档案和分成规则，也可关联已有账号。密码使用现有哈希机制，已有角色的权限配置保持不变。

## 本次升级的字段迁移

已安装客服模块的服务器，需要先补齐 `021_svc_staff_settlement_cycle.sql` 和 `022_svc_staff_timing.sql`：为 `svc_staff` 增加结算周期及两个个人时效列。迁移只加缺失列，可重复执行，保留已有档案值；不初始化比例、不补历史订单或重算账本。

**先备份，再补列，最后更新代码。** 更新器的 `--migrate` 只执行通用数据库迁移，不能代替这两个客服迁移。不要为这三个字段重跑整个客服初始化，以免重新补入之前撤销的默认菜单授权。

以下步骤在已安装后台且已有 `svc_staff` 表的服务器执行；未安装客服模块时先按《客服工作台与分成开发验收》完成模块安装。服务器安装目录不是 `/opt/luxiaoming-admin` 时需调整命令中的对应路径。

```bash
set -e
cd /opt/luxiaoming-admin
sudo systemctl stop luxiaoming-admin
sudo node scripts/backup-mysql.cjs
```

接着从旧安装目录借用已安装依赖和服务器 `.env`，只执行新包中的两个加列迁移：

```bash
sudo -H -u luxiaoming -g luxiaoming -- node - /tmp/luxiaoming-admin-linux-20261113-updater-r1 <<'NODE'
'use strict';
const path = require('node:path');
const { createRequire } = require('node:module');
const installed = createRequire(path.join(process.cwd(), 'package.json'));
installed('dotenv').config({ path: path.join(process.cwd(), '.env'), quiet: true });
process.env.DB_AUTO_MIGRATE = 'false';
const { source, mode } = installed('./server/lib/selectSource.cjs')();
const release = path.resolve(process.argv[2]);
const { statements, applyStatement } = require(path.join(release, 'scripts/migrate-customer-service.cjs'));
(async () => {
  try {
    if (mode !== 'mysql' || typeof source.transaction !== 'function') throw Object.assign(new Error('MySQL unavailable'), { code: 'MYSQL_UNAVAILABLE' });
    await source.transaction(async conn => {
      for (const file of ['021_svc_staff_settlement_cycle.sql', '022_svc_staff_timing.sql']) {
        for (const sql of statements(path.join(release, 'server/migrations', file))) await applyStatement(conn, sql);
      }
      const [columns] = await conn.query("SELECT column_name FROM information_schema.columns WHERE table_schema=DATABASE() AND table_name='svc_staff' AND column_name IN ('settlement_cycle','link_valid_days','observe_days')");
      if (columns.length !== 3) throw Object.assign(new Error('Staff columns missing'), { code: 'STAFF_COLUMNS_MISSING' });
    });
    console.log(JSON.stringify({ ok: true, migrations: ['021', '022'], existingRowsPreserved: true }));
  } finally { await source.close?.(); }
})().catch(error => { console.error(JSON.stringify({ code: error.code || 'SVC_STAFF_MIGRATION_FAILED' })); process.exitCode = 1; });
NODE
```

MySQL 的 `ALTER TABLE` 会隐式提交。补列失败时保持服务停止，检查备份和已有列后处理，不能按已自动回滚处理。健康接口不检查这些业务列，须以上述三列检查为准。

补列成功后，使用包含更新器与 helper 的完整新包执行更新：

```bash
sudo bash /tmp/luxiaoming-admin-linux-20261113-updater-r1/deploy/linux/update.sh /tmp/luxiaoming-admin-linux-20261113-updater-r1.tar.gz
```
