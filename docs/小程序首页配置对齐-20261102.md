# 小程序首页配置对齐

2026-11-02。以 `luxiaoming_交付包/miniprogram/pages/index/index.wxml`、首页数据服务和公开 `getHomeData` RPC 为依据调整后台的「内容管理 → 小程序首页」。

## 可编辑内容

| 设置 | 对应首页行为 |
| --- | --- |
| 图片 / 视频轮播、视频封面、城市、排序、点击目标 | 自定义素材优先，否则按选中样片顺序展示，最多 6 张；均未配置时沿用服务端公开展示样片兜底 |
| 特色专区显隐 | 地图探点、旅拍灵感、影像周边三个固定入口 |
| 照片留影显隐及推荐 | 公开照片商品，按城市、所选打卡点过滤 |
| 视频摄像显隐 | 公开短视频单品，按热度及所选打卡点过滤 |
| 旅拍套餐显隐及推荐 | 推荐标记结合热度展示，按所选打卡点过滤 |

预览按当前首页区块顺序排列；可切换预览城市、打卡点和轮播。预览城市仅用于后台查看，不写入游客默认城市设置。预览是后台数据的版式示意，游客端还会使用真实城市和公开商品过滤结果。

## 移除的表单

默认城市、服务标识、首页主副标题、预约人数、好评率、活动公告、快捷入口、独立周边区块及推荐、无效的轮播标题与定时生效、外部网页跳转、模块排序，以及探索页轮播和其他页面装修 / 多页面预览。

这些内容没有对应的当前首页展示能力。其他页面已有的 `exploreBanners`、`pageModules` 等存储数据继续保留，保存首页时不生成其他页面的新默认配置。

## 同步修复

- 四个显隐开关使用统一的公开模块 key。小程序首页构建显隐映射时保留 `visible:false`，避免过滤后又被视为默认显示。
- 读回公共轮播、模块和推荐设置，避免旧编辑快照覆盖游客实际读取的数据；兼容历史仅有 `banners` 的文档。
- 保存时让顶层设置与编辑快照一致，防止 MySQL 往返后删除的轮播或清空的推荐重新出现。
- 替换素材、清空点击目标或修改城市时，清理冲突的旧字段；「不跳转」不会再被旧链接覆盖。
- 停止每次保存时把后台列表前六个打卡点自动置顶，保持首页热榜按热度加载。
