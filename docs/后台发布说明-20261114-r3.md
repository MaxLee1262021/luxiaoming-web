# 后台发布说明 2026-11-14 r3

发布包：`luxiaoming-admin-linux-20261114-updater-r3.tar.gz`，从当前 `luxiaoming-admin-交付包` 工作区生成，包含现有功能和本轮一级菜单排序修复。

## 菜单修复

原先登录时会将旧菜单名称规范化，但进入权限管理或保存后刷新时，会用数据库中的旧名称“摄影师分成”覆盖导航配置。这个名称无法匹配固定分组顺序，因此被排在末尾；同时刷新还会丢失分成菜单的展示顺序。

现在登录与权限页刷新共用导航规范，一级顺序保持“客服分成管理 → 摄影师分成管理 → 商家分成管理”，摄影师分成位于财务管理和系统安全之前。分成菜单继续按“分成配置、分成明细、人员列表、结算管理、客服端／摄影端”展示；人员列表分别显示客服列表、摄影师列表。

权限页仍反映菜单删除、停用及自定义目录结构。摄影师模块安装及新建账号时补建菜单的入口也统一写入“摄影师分成管理”。旧数据库菜单由展示层兼容，本次修复无需数据库结构或数据迁移，也无需重跑摄影师模块安装。

更新后刷新浏览器，进入“系统安全 → 权限管理”，离开后再次进入，确认“摄影师分成管理”始终位于客服分成和商家分成之间。需要回退时使用更新器保留的旧代码；本次菜单修复没有新增数据库迁移。
