# 预约定金与须知配置

后台入口为「内容管理 → 预约配置」。填写默认定金比例、预约须知正文（每行一条）和须知版本，点击「保存预约配置」。修改须知正文时必须同步更新版本。约拍定制定价为选填，标准商品仍使用各自售价。

照片留影和视频摄像编辑页的「定金比例（%）」可以设置商品独立比例，留空表示使用默认定金比例。输入 30 表示 30%，输入 1 表示 1%，输入 0 表示不收取定金。旅拍套餐继续使用原有套餐价格区的比例设置。

小程序重新进入预约填写页时会重新读取默认比例和须知，按商品独立比例优先、全局默认比例兜底计算定金。未配置有效比例或预约须知正文及版本时仍会阻止提交。配置保存只更新预约相关字段，保留其他全局设置。

本次代码不填写实际经营比例、须知内容或版本，不修改现有商品或订单。上线后需由运营人员保存实际规则。数据库已有扩展字段存储承接配置；现有账号的新增菜单授权遵循系统权限配置。
