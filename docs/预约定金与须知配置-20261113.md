# 预约定金与须知配置

后台入口为「内容管理 → 预约配置」。填写默认定金比例、预约须知正文（每行一条）和须知版本，点击「保存预约配置」。修改须知正文时必须同步更新版本。约拍定制定价为选填，标准商品仍使用各自售价。

照片留影和视频摄像编辑页的「定金比例（%）」可以设置商品独立比例，留空表示使用默认定金比例。输入 30 表示 30%，输入 1 表示 1%，输入 0 表示不收取定金。旅拍套餐继续使用原有套餐价格区的比例设置。

小程序重新进入预约填写页时会重新读取默认比例和须知，按商品独立比例优先、全局默认比例兜底计算定金。未配置有效比例或预约须知正文及版本时仍会阻止提交。配置保存只更新预约相关字段，保留其他全局设置。

同一页面下方的「隐私配置」用于设置小程序「我的 → 隐私政策」页的标题和完整正文。标题最多 128 字符，正文最多 20000 字符，正文换行按段落展示。点击「保存隐私配置」独立保存，无需先填写定金和预约须知。保存后显示服务端记录的最近保存时间，小程序重新进入隐私政策页读取最新内容和标题。两个保存按钮分别保存各自区域，不提交另一区域的草稿。

隐私配置写入 `siteConfig/global.privacyPolicy`，服务端记录更新时间、同步旧版 `privacyText` 并清除旧结构化段落，防止旧内容覆盖新正文。后台兼容读取已有纯文本和结构化隐私政策；无需数据库迁移。空正文不允许保存，原有菜单及内容编辑权限继续适用。

「预约成功页温馨提示」用于设置小程序「预约申请已提交」页面底部「温馨提示」的正文，支持多行纯文本，最多 20000 字符。点击「保存温馨提示」单独保存，无需填写定金、预约须知或更新须知版本，也不提交其他区域的草稿。未设置、清空或读取失败时，小程序继续展示原默认提示。重新进入成功页时读取最新配置。

温馨提示保存在 `siteConfig/global.bookingSuccessTips`，由 `getBookingConfig` 返回，使用现有扩展字段存储，无需数据库迁移。需要更新后台和小程序代码后，运营人员才可通过此处设置小程序实际展示的内容。

本次代码不填写实际经营比例、须知内容、政策正文或版本，不修改现有商品或订单。上线后需由运营人员保存实际规则。数据库已有扩展字段存储承接配置；现有账号的新增菜单授权遵循系统权限配置。
