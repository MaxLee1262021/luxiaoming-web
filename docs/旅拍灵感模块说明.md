# 旅拍灵感

后台入口：内容管理 → 旅拍灵感。按照用户提供的「演示.html」改造列表与独立编辑页，继续复用 guides 集合、现有权限、OSS 上传和回收站。

## 后台操作

- 列表提供标题、正文及打卡点搜索、点位筛选和「全部 / 已发布 / 草稿」筛选。置顶内容优先，其余按更新时间排序。
- 「已发布 / 草稿」与「前端显示 / 隐藏」独立；显示开关不会发布草稿，发布隐藏内容也不会自动打开显示。支持置顶、取消置顶和确认删除。
- 新建或编辑进入独立页面：50 字以内标题、独立首页封面、富文本正文、多个关联打卡点、一个关联商品。
- 「初始数据」可填写初始浏览人数和初始评分，默认均为 0。浏览人数为 0–2147483647 的整数；评分为 0–5 分，最多一位小数。存草稿和发布均校验，编辑已有文章会回显原有数据。
- 封面支持点击和拖拽上传，建议 1280 × 720，支持 5MB 以内 JPG / PNG / WebP。正文支持段落、标题、粗体、斜体、下划线、列表、引用、分割线，以及图片和视频混排；可粘贴或拖拽图片，视频支持 MP4 链接和 100MB 以内的本地 MP4 上传。实际文件使用原有 OSS 流程，不保存本地临时地址。
- 正文「上传文件」支持 PDF、DOCX、XLSX、PPTX、TXT、CSV，单文件不超过 20MB，也支持拖拽或粘贴文件。每个文件保留原插入位置，多图批量上传、失败重试不会打乱顺序；编辑器内显示进度，可重试或移除失败项。上传未完成或失败项未处理时禁止保存。
- 图片上传独立于旅拍灵感新字段的就绪状态。已登录且接口可用、仅数据库缺少新版字段时仍可上传；文章保存会明确提示需要更新数据库，不会误报保存成功。真实断网或会话失效仍拒绝操作。
- 商品按关联点位分组，候选为可预约照片留影、旅拍套餐和视频单品；全篇最多选择一个，允许取消选择。删除该商品所属的关联点位时同时清空商品；删除其他点位则保留。
- 「存草稿」「发布 / 更新发布」「预览 → 确认发布」均保存当前内容。保存要求标题、有效封面、正文文字或媒体、至少一个有效打卡点。草稿保存后停留编辑页，发布后返回列表。
- 编辑已有内容时保留原始记录；返回列表、切换菜单或退出登录前提示未保存修改。保存期间禁止继续编辑或离开，正式会话断网不会退回本地保存。依赖加载失败会提示重试。

## 小程序展示

首页、旅拍灵感列表、搜索和点位入口统一过滤草稿、隐藏和删除内容，置顶优先。点位入口按多个关联点位筛选。

旅拍灵感列表的信息流提供「默认排序 / 浏览人数 ↓ / 评分 ↓」。后两项按所选数值从高到低排列，相同数值沿用置顶、更新时间顺序；默认排序保留原规则。分类切换及重新加载后保留当前排序，打卡点入口的关联文章同样生效。顶部置顶轮播仍按后台置顶顺序展示。

新正文按「封面 → 标题 → 混排正文 → 多个关联点位 → 预约同款」呈现。图片支持放大，视频使用原生播放器并保留正文中的位置。每个关联点位均可进入对应详情；预约使用所选商品所属点位，并继续携带 shopId、scene 来源。商品下架、隐藏、删除、移出所属点位或该点位不再公开时隐藏预约入口。

附件按正文位置显示文件卡片，包含名称、大小及下载进度。PDF、Word、Excel、PPT 下载后使用微信文档预览；TXT、CSV 提供下载链接供浏览器保存。下载和预览失败均提示重试，下载期间拦截重复点击。

旧纯文字和媒体轮播继续展示。编辑旧文章时转为富文本并保留原有多个点位，保存时按新规则补齐必填项。历史文章仅操作显隐、置顶时不强制补齐内容。

## 数据与部署

- `contentHtml` 保存清洗后的 HTML；`content` 和 `description` 保留纯文字兼容，`mediaItems` / `mediaUrls` 保留媒体顺序。新正文的 `mediaType` 为 rich，可同时含图片和视频；清洗前后均限制正文 UTF-8 60KB，媒体只保存 URL。
- 附件保存为受控 `/api/media/file_…` 链接及 `attachments` 元数据，服务端按真实文件记录核验归属、名称、大小与 MIME，验证实际文件内容后才可引用。附件上传仅用于旅拍灵感；其他素材集合及私有订单用途保留原限制。下载使用 OSS 临时签名并强制附件下载，附件功能无需新增数据库字段。
- `spotIds` 保存多个关联点位，`spotId` 保留首项兼容。`targetProductSpotId` 保存唯一预约商品所属点位；`targetProductType` 为 album / package / video，`targetProductId` 为商品标识，`targetPackageId` 保留旧字段兼容。
- `status` 保存草稿或已发布，`isShow` 控制显示，`isTop` 控制置顶。旧 visible / enabled 显隐别名同步维护。详情提供 `spots` 和 `bookingProduct.spotId`，商品点位按实际商品关系计算，含组合套餐。
- 初始浏览人数和初始评分分别复用已有 `readCount`（INT）和 `score` 数值列，本次功能无需新增列或数据库迁移。列表、详情及首页使用同一组数值；明确填写 0 时不会被历史 `views` 覆盖。现有详情读取没有自动累加浏览数或用户评分统计逻辑。
- `listGuides` / `getGuides` RPC 支持 `sortBy: "readCount"` 或 `sortBy: "score"`，均为降序；省略或传其他值沿用默认排序。小程序列表切换排序时使用已加载的完整公开文章集，不额外请求接口。
- 新富文本文章关联部分点位不公开时，仅保留可公开点位；旧文章沿用原有整篇可见性规则。
- MySQL 新增 `contentHtml`、`targetProductSpotId` 字段，初始化 SQL 和字段字典已同步。现有库应依照项目迁移流程先备份，再执行 `npm run migrate:mysql -- --apply`，更新后台服务并重新发布小程序。本次仅修改源码和本地验证，没有执行真实数据库迁移或上线。

## 后台列表查询优化（2026-11-09）

菜单切换和列表组件初始化同时加载数据时，共用当前进行中的请求；返回菜单或点击重试仍重新读取，不跨请求缓存内容。服务端模块接口在一次 GET 内复用集合读取，并按显示状态计算所需的关联数据加载上下文，避免重复读取整套内容目录。

隔离回归中，旅拍灵感菜单的 `guides,spots,series,albums,packages` 数据包由 11 次业务集合读取降至 6 次，每个集合只读一次；保留套餐显示规则必需的周边商品读取。旧版 `/api/collection/guides` 列表由 7 次集合读取降至 3 次，仅读取灵感、打卡点和系列。上述数字不含鉴权读取，也不等同于 SQL 条数或线上耗时。

正文、媒体、商品关联及编辑保存契约保持兼容。无需数据库迁移或新增依赖；代码完成后需更新后台服务和浏览器静态资源，线上耗时待部署后对比请求日志中的 `durationMs`、`dbQueryCount` 和 `dbDurationMs`。回归见 `server/tests/admin-content-performance.test.cjs`、`src/tests/menu-lazy-loading.test.cjs` 和 `src/tests/guide-page.test.cjs`。

本次本地验证：`npm run check` 119 个模块通过，`npm run build` 通过，`npm test` 789 项通过、4 项按现有环境条件跳过、0 失败。
