# 后台发布说明：2026-11-19 r2

发布包：`luxiaoming-admin-linux-20261119-updater-r2.tar.gz`。包含当前正式后台工作区的全部源码，相对当日 r1 主要增加商品小程序外链、客服企微自动邀请及相关权限、界面和异常处理。

## 商品小程序外链

客服工作台新增「商品小程序外链」，统一展示照片留影、视频摄像、旅拍套餐及周边商品，支持搜索、筛选、1/7/30 天链接生成和复制。服务端使用微信 URL Link，生成前校验具体商品当前可见性，使用既有小程序详情页，无需为此修改小程序源码。

复用服务器 `WX_APP_ID`、`WX_APP_SECRET` 和可选 `WX_ENV_VERSION`。凭据、微信 token 不发送到浏览器；未配置、微信拒绝或页面未发布时明确报错。真实微信链接的手机落地页仍须上线联调。

本功能没有业务表结构迁移。本会话已在项目当前配置的数据库初始化 `productLinks` 菜单并核对超管、客服授权，无须在同一数据库重复执行。部署其他数据库时可运行 `node scripts/install-product-links-menu.cjs --apply`；脚本保留已存在的菜单及授权。详见[商品小程序外链](商品小程序外链-20261119.md)。

## 客服企微自动邀请及数据库升级

本包同时包含当前工作区的客服企微同步功能：新增或关联客服账号后创建或复用企微成员、加入客服部门、提交邀请、保存同步状态和分享映射；超管可重试失败项。邀请成功不代表成员已确认加入。

**相对 r1 新增了专用数据库迁移。即使暂不启用企微同步，也应在启动本版前备份并补齐客服同步字段。商品外链菜单初始化不能替代此次迁移。**

执行新包的 `npm run migrate:wecom-contacts -- --apply`，为 `svc_staff` 添加六个可空企微字段，并在缺失时创建共享表 `lxm_share_staff_map`。迁移可重复执行，保留历史映射、分成比例、权限及支付接入时间，不邀请历史客服。本次打包未执行该迁移。

通用更新器的 `--migrate` 只运行 `migrate:mysql`，不能替代企微专用迁移。旧版项目尚无该命令时，应先解压本包到临时目录，使用新脚本及服务器既有配置、依赖完成迁移，再更新应用。例如，在备份完成后：

```bash
cd /tmp
tar -xzf luxiaoming-admin-linux-20261119-updater-r2.tar.gz
sudo env NODE_PATH=/opt/luxiaoming-admin/node_modules \
  DOTENV_CONFIG_PATH=/opt/luxiaoming-admin/.env \
  node -r dotenv/config /tmp/luxiaoming-admin-linux-20261119-updater-r2/scripts/migrate-wecom-contacts.cjs --apply
```

使用实际应用路径替换示例路径；迁移失败时停止升级并核查，不跳过直接启动新代码。企微凭据和启用方式见[客服企微自动邀请](客服企微自动邀请-20261119.md)。本次打包未连接数据库、未调用企微邀请或真实微信外链接口。

## 上传、校验和更新

```bash
scp luxiaoming-admin-linux-20261119-updater-r2.tar.gz luxiaoming-admin-linux-20261119-updater-r2.tar.gz.sha256 用户名@服务器IP:/tmp/
```

在服务器执行校验，按前述要求完成企微专用迁移后再更新：

```bash
cd /tmp
sha256sum -c luxiaoming-admin-linux-20261119-updater-r2.tar.gz.sha256
sudo bash /opt/luxiaoming-admin/deploy/linux/update.sh /tmp/luxiaoming-admin-linux-20261119-updater-r2.tar.gz
```

默认源码包不包含 `.env`、`node_modules`、测试、业务数据、上传文件、备份、支付密钥和证书，沿用服务器配置。此次仅打包后台，不上传、不部署、不发布小程序。
