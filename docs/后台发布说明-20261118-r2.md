# 后台发布说明：2026-11-18 r2

发布包：`luxiaoming-admin-linux-20261118-updater-r2.tar.gz`。从当前正式后台工作区生成，包含截至打包时的全部后台源码修改。本次在 `20261118-updater-r1` 的基础上补充周边商品规格样式设置。

## 周边商品样式

- 周边商品编辑支持为单规格和每个多规格选项填写可选样式，最多 80 个字符，并实时预览「规格【样式】」。留空仅展示规格。
- 同一尺寸可以维护不同样式，各自设置售价和库存。新建同尺寸规格时自动补充区分编码，不要求运营人员手工编造编码。
- 购买接口返回样式及组合展示文字；购物车、结算、实物订单和套餐实物履约保存选中样式，历史订单不随商品编辑改变。
- 后台实物订单列表、详情及交易库存显示组合规格文字，便于按所选样式履约。
- 保留现有库存保护：已初始化交易库存的商品不能通过商品编辑直接增删、重排规格或切换规格模式；实际库存调整使用「实物订单 → 销售配置」。

## 数据库与配套小程序

相对 `20261118-updater-r1` 没有新增数据库结构变更，样式保存在现有商品和交易快照字段内。本次普通更新不需要 `--migrate`，也不执行数据迁移。

本包仅包含后台。小程序商品选购弹窗参照示例图展示商品图、价格、数量及「尺寸【样式】」选项，属于独立小程序源码，需要另行编译发布；更新后台不会自动发布小程序界面。

## 打包与部署

按《后台发布打包规范》执行 `npm run check`、`npm run build`、`npm test`，并检查部署脚本语法，再通过项目自带 `package:linux` 生成包。默认不包含真实 `.env`、依赖、数据库、测试、上传文件、支付密钥或证书，继续使用服务器现有配置。

上传发布包及校验文件：

```bash
scp luxiaoming-admin-linux-20261118-updater-r2.tar.gz luxiaoming-admin-linux-20261118-updater-r2.tar.gz.sha256 用户名@服务器IP:/tmp/
```

在服务器校验并更新：

```bash
cd /tmp
sha256sum -c luxiaoming-admin-linux-20261118-updater-r2.tar.gz.sha256
sudo bash /opt/luxiaoming-admin/deploy/linux/update.sh /tmp/luxiaoming-admin-linux-20261118-updater-r2.tar.gz
```

打包过程不连接生产数据库、不上传、不部署，也不触发支付或退款。首次安装或从尚未安装商家分成、实物交易表的更早版本升级，仍按对应历史部署文档处理。
