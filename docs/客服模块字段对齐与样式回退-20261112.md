# 客服模块字段对齐与样式回退

本次按用户更正后的要求处理：页面沿用修改前的后台风格；DEMO用于核对业务字段，字段不能遗漏，也不能用近义名称替换。此前的原型配色和布局重构已撤回。

## 样式恢复

- 移除原型专用的蓝/绿主题、白色侧栏、顶部品牌栏及KF/CS编号导航，恢复原管理后台侧栏、账号栏和菜单。
- 恢复修改前发布包中的Element Plus表格、表单、弹窗、720px详情抽屉及原有暖色页面样式。公共客服样式与修改前发布包保持一致。
- 不回退已确认的业务规则：定金提成、主管代办、实物收货完成、人工标签、复核日期及共享日历继续保留。

## 字段补齐

| 区域 | 已补齐或恢复的原字段 |
| --- | --- |
| 工作台指标 | 主指标区严格保留六项及原顺序：待认领新单、待确认时间、待派单、拍摄中待跟进、待处理客诉、本月预估分成。金额位于第六张卡；今日拍摄、复购预占放补充信息，不挤占主卡片。 |
| 订单承接 | 客户、商品、实收、支付时间、来源 / 归属、状态等原字段；期望拍摄时间作为需求新增字段保留，不能挤掉原字段。 |
| 预占订单 | 实收、上次服务单、剩余时间及接单/放弃操作；倒计时继续使用服务端值。 |
| 跟进与完成 | 预约时间、摄影师、预计提成、拍摄时间、完成时间、分成金额等，按进行中/已完成分别展示。 |
| 客诉及调账 | 关联订单、责任方、问题描述、问题、对提成、状态、改判为、改判原因，以及时间/客服/动作/金额/说明。 |
| 订单详情 | 预约提醒、复购来源、回流记录、订单净额、该类目比例、我的提成、摄影师分成、毛利占比。 |
| 分成设置 | 当前版本、当前生效比例、四类比例、版本历史、单独设置比例、复核日、绑定与解绑记录及完整共享时效字段。 |
| 客服人员 | 分成时效恢复为独立字段，不再被标签/复核日替换；人员详情补回本月分成、累计分成、承接主管和版本状态。 |
| 新增客服 | 姓名、手机号、承接主管、合作起始日、后台账号、这个人的比例怎么定、四类比例、链接有效期（天）、结算等待期（天）、多久结一次、开通说明。 |
| 我的分成 | 本月报酬（含基本工资）、本月提成、基本工资、累计提成、我的比例五项原指标；原分阶段汇总作为补充保留。 |

表头、详情和表单按其在DEMO对应位置的原名核对。同一含义在DEMO不同位置使用不同名称时，各位置分别保留，例如人员列表“主管”和表单“承接主管”。

主区域还需核对数量与顺序，而不仅是字段存在：人员主表保持DEMO十列，单独设置比例表保持DEMO六列；新增手工标签、复核日放在人员详情和维护弹窗中，不能插进原主表挤开“操作”。工作台六项指标采用独立卡片，保留当前后台的字体、暖色边框、配色及侧栏。

## 数据与规则边界

所有金额、比例、时效和人员信息来自真实接口。个人报酬中的工资只用于展示，不计入提成结算单应付金额。后台账号按已有真实账号名解析关联，不创建演示账号或密码。

个人时效字段显示当前共用配置，不展示实际无法保存的个人覆盖选项；相关规则继续以定稿需求为准。发链页保留“选择周边商品”原字段，当前只读显示真实订单关联商品，不伪造可选商品或来源关系。

毛利告警线未在已确认业务配置中给出，保留原字段并明确显示“未配置”；摄影师分成和毛利占比依真实账本展示，不能硬编码演示中的20%或55%。没有数据时显示空值或未生成状态。

本次未执行SQL、数据库迁移或数据清理。
