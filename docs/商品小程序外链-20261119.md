# 商品小程序外链

入口：客服工作台 → 商品小程序外链。

页面汇总照片留影、视频摄像、旅拍套餐及周边商品，展示封面、名称、编号、价格、简介及可用状态，可按关键词、类型和状态筛选。选择 1、7 或 30 天有效期后，点击对应行的“生成外链”，在结果弹窗复制 HTTPS 链接。

## 部署

- 复用服务端 `WX_APP_ID`、`WX_APP_SECRET`，凭据不会返回浏览器。默认生成正式版链接；沿用 `WX_ENV_VERSION` 时页面明确提示体验版或开发版。
- 服务端应能访问微信接口，且满足微信平台对主体资格、接口权限和 IP 白名单的要求。对应详情页面须已在小程序发布。
- 超管更新代码后即可看到入口。为存量 MySQL 客服角色安装菜单，可先运行 `node scripts/install-product-links-menu.cjs` 查看安装范围，再在部署时运行 `node scripts/install-product-links-menu.cjs --apply`。脚本只新增缺少的菜单，并授予现有超管、客服及客服主管角色；已存在的菜单和授权保持权限管理中的配置。也可在权限管理中新增指向 `productLinks` 的菜单并分配给指定角色。
- 新安装的客服模块及新建的客服角色包含此入口。接口同样检查菜单授权；仅有商品内容权限或其他工作台菜单不能调用该接口。
- 无业务表迁移，无须更新小程序源码。

## 行为

后台显示所有未删除目录记录，生成时再次依据小程序公开目录和目标详情页检查可访问性。下架、审核未通过、依赖不可见等记录不可生成。商品后续下架会影响已发出的链接访问；微信有效期不保证商品始终在售。

| 类型 | 页面 | 参数 |
| --- | --- | --- |
| 照片留影 | `pages/photoCollection/photoCollection` | `albumId` |
| 视频摄像 | `pages/videoProductDetail/videoProductDetail` | `productId` |
| 旅拍套餐 | `pages/photoPackageDetail/photoPackageDetail` | `packageId` |
| 周边商品 | `pages/peripherals/peripherals` | `id` |

服务端调用[微信获取 URL Link 接口](https://developers.weixin.qq.com/miniprogram/dev/server/API/qrcode-link/url-link/api_generateurllink.html)，返回真实微信 HTTPS 链接。页面路径与查询参数由服务端固定映射，客户端不能传入任意跳转地址。有效链接在单进程内复用以减少重复生成；重启后可重新生成，微信已签发的链接仍按原有效期生效。

未配置凭据、微信请求失败、配额不足或页面未发布时展示明确错误，不生成替代链接。复制受浏览器权限影响时，弹窗支持手动选择链接复制。

## 验证

单元与 HTTP 测试使用隔离目录、授权和微信响应，覆盖四类路径、当前可见性、重复请求复用、token 刷新、错误处理及授权边界。浏览器验证使用合成数据，不调用真实微信接口、不写入真实数据库。上线后仍需用真实微信凭据生成一条链接，并在手机微信中验收实际落地页。
