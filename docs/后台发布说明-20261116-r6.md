# 后台发布说明：2026-11-16 r6

发布包：`luxiaoming-admin-linux-20261116-updater-r6.tar.gz`，由当前正式后台工作区生成，包含 r5 的商品标签修复及本次套餐适用打卡点修复。

## 套餐与订单适用打卡点

- 套餐公共接口完整返回包含商品的全部适用打卡点，覆盖无拍摄风格、跨风格、多地点以及视频、周边商品关联。
- 预约数据接口返回完整地点列表，供小程序套餐详情和预约确认页展示。
- 新订单由服务端生成每项商品及整单的适用地点快照，忽略客户端传入的地点列表；后续套餐改动不覆盖下单快照。
- 历史订单没有适用地点快照时，仅在读取时按当前可见商品配置补全，并标记为当前套餐适用范围，不修改历史订单。单独选定的拍摄地点仍独立保留。
- 明确为空的地点快照保持为空；公共响应仅返回地点 ID 和名称。

## 数据库与小程序

本次没有新增数据库结构，无需执行 SQL 或追加 `--migrate`。现有 MySQL 存储可保存并读取地点快照，已验证订单及预约数据的存储往返。

后台包不包含小程序。配套小程序修改位于独立小程序源码目录，需要重新编译或发布，套餐详情、预约确认页及订单详情才能展示完整地点列表。

## 打包与验证

发布前执行 `npm run check`、`npm run build`、`npm test`，并检查三个 Linux 部署脚本语法。打包后核对 SHA256、单一顶层目录、关键源码一致性、脚本 LF/0755，以及更新脚本和 helper 配对。

默认包不包含 `.env`、数据库、依赖目录、测试目录和密钥；更新器保留服务器现有配置。
