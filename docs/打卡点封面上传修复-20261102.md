# 打卡点封面上传修复

完成日期：2026-11-02。

## 问题与改动

打卡点使用共享编辑弹窗，但通用“详情与素材”区排除了打卡点，专属表单又没有封面和介绍输入；新增展示校验却要求填写这两项，导致无法完成上传和保存。

- 新增和编辑打卡点均提供封面上传、即时预览、替换、已有图片链接及介绍输入。支持 JPG、PNG、WebP，沿用现有 OSS 上传、进度、失败重试及保存等待机制。窄屏上传区按纵向排列。
- 编辑草稿兼容历史图片字段，上传完成只回填开始上传时的草稿，点击保存后才更新点位。保存同步 `cover / coverUrl / coverImage / image`，防止换图或清空后恢复旧图片。
- 后台公开 RPC、小程序首页首批和追加点位、打卡点详情统一按 `cover > coverUrl > coverImage > image` 读取首个非空字符串；首页和详情展示同一张图片。
- 使用已有媒体接口、文件归属检查和数据库存储，无需数据库迁移。
