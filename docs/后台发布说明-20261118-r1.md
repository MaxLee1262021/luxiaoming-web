# 后台发布说明：2026-11-18 r1

发布包：`luxiaoming-admin-linux-20261118-updater-r1.tar.gz`。从当前正式后台工作区生成，包含截至打包时的全部后台源码修改；以下说明相对 `20261117-updater-r2` 的主要变化。

## 商家码归属及统计

- 最近一次有效扫码的商家持续享有订单分成，直到扫描下一家商家码；退出小程序或客服推荐点击不清除归属。
- 自主和客服推荐订单使用相同的商家归属，各自沿用对应分成比例；移除当前配置界面的旧归属时效和候选商家筛选说明。
- 当前归属人数按每名客户最近的有效归属统计，不再把同一客户同时计入多个历史商家；保留历史扫码事实。
- 修复短时间内 A→B→A 扫码的去重边界。换码前的有效归属可继续下单，失效旧码不能建立新归属。
- 独立实物订单接入商家分成、退款冲抵、商家脱敏订单进度及业务城市统计；运费排除，套餐履约子单不重复计提。
- 订单按既有支付判定时点取归属；支付后的扫码不改变此前订单结果。已入账历史分成不自动重算。
- 归属查询失败时隐藏相应订单，避免向旧来源商家显示其他商家的订单。

完整规则见《商家码最近扫码归属规则-20261118.md》。

## 预约与订单显示

- 后台预约配置支持独立维护预约成功页“温馨提示”，保存后由公共预约配置接口返回，保留换行并支持清空恢复默认提示。
- 小程序订单接口补齐确认支付及退款金额的展示，避免把未确认的应付金额当作实付。

## 数据库与配套小程序

与 `20261117-updater-r2` 相比，本次没有数据库结构或迁移脚本变更；已安装商家分成及实物交易表的环境普通更新不需要 `--migrate`。更早且未安装这些表的环境，应先按既有商家分成和实物交易部署文档完成安装；本次打包不执行任何数据库操作。

本包只包含后台。最近扫码的本地持久化、扫码顺序重试、支付前扫码同步、预约成功页“联系客服”按钮及提示展示属于独立小程序源码，仍需重新编译和发布小程序。单独更新后台不会发布该按钮。

## 打包及校验

执行 `npm run check`、`npm run build`、`npm test`，检查三个 Linux 部署脚本语法后，使用项目自带 `package:linux` 脚本打包。交付前核对归档 SHA256、单一顶层目录、源码一致性、部署脚本 LF/0755，以及更新脚本与 helper 配对。

默认包不包含 `.env`、数据库、依赖目录、测试目录、支付密钥和证书。运行配置使用服务器原有配置；生成发布包不上传、不部署、不触发支付或退款。
