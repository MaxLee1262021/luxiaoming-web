# 角色体验复查记录

## 2026-06-29 本轮复查结论

- 超管切换角色预览时，必须进入该角色默认首页，并清理上一个角色残留筛选，避免“菜单显示 A、内容还像 B”的串台体验。
- 订单列表的订单号必须作为高频打开详情入口，右侧编辑/查看按钮作为辅助入口；客服日常不应依赖横向滚动后的固定操作列。
- 订单详情中，客服/超管可编辑客服处理、金额核对、加购和内部备注；摄影师、商家只能查看必要订单信息和操作时间线。
- 摄影师不能查看商家来源链路和完整联系方式；商家只能查看自身门店范围，手机号/微信号需要脱敏或隐藏。
- 取消订单必须同步写入订单操作时间线和全局操作日志，并进入回收站；客服不能永久删除，超管在回收站恢复或彻底删除。
- 人员权限编辑不能只做展示，账号自定义权限应参与按钮能力判断；正式版后端仍需做二次鉴权。

## 2026-06-29 内容商品逻辑校正

- 打卡点下面是系列，系列下面是照片单品，照片单品下面是样片。
- 系列不是商品，系列只是拍照风格、主题、氛围和样片组织方式，不单独标价。
- 照片单品才是商品，需要独立价格；客人看中照片单品内样片后，点击照片单品预约。
- 套餐是独立商品入口，在“套餐设置”创建，再通过下拉关联打卡点，或设置为全局主推套餐。
- 左侧“内容商品”保留公开内容与服务配置入口：打卡点设置、商品上下架、套餐设置、增值服务、摄影周边。
- 商品上下架是对标抖音来客的轻量商品货架，只汇总公开售卖的照片单品、套餐产品、摄影周边，用于上架/下架、价格和标签调整。
- 增值服务不是公开商品，只是客服服务客人时在订单跟进中添加的内部服务项；配置入口放在内容商品下，订单履约只保留日常订单处理和摄影师任务。
