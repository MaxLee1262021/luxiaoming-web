# 客服账号直接创建

原“新增客服”只能保存档案或关联权限管理中已有的账号，不能直接开通登录账号。

现在进入“客服分成管理 → 新增客服”，默认选择“新建登录账号”，填写后台账号和初始密码。其余姓名、手机号、合作起始日、基本工资、分成比例和结算周期按原流程填写。保存后，账号、客服档案、初始比例及建档日志在同一事务中写入；使用填写的账号密码即可登录后台。

选择“关联已有账号”可沿用原有账号，无需填写内部账号 ID，也不会修改该账号的密码。新建账号重名时应更换账号或选择关联模式，系统不会覆盖已有账号。

- 账号去除首尾空白，长度不超过 128 字符，不允许控制字符或平台保留的 admin 账号。
- 初始密码为 8–128 位，包含字母和数字；密码按原样处理，使用现有 scrypt 哈希保存。
- 新账号绑定 `service` 角色和本人客服档案。已有角色的权限保持管理员配置；首次创建客服角色时初始化工作台和本人分成菜单，不授予人员管理、比例管理或财务结算权限。
- 保存失败整体回滚，保留表单便于修改重试。保存成功、重置、取消和离开页面会清除表单密码；查询、建档日志和响应均不包含密码。
- 账号创建使用已有认证结构。随后增加的个人时效设置需要执行 `022_svc_staff_timing.sql`，见 [客服个人时效编辑](客服个人时效编辑-20261113.md)。

验证命令：

```sh
node --test server/tests/svc-account-provisioning.test.cjs src/tests/svc-account-ui.test.cjs
npm run check
npm run build
npm test
```

可选真实 MySQL 验证：`RUN_ISOLATED_SVC_MYSQL=1 node --test server/tests/svc-mysql-isolated.test.cjs`。该测试创建随机隔离测试库，测试账号绑定、密码哈希、重名回滚及日志保存失败回滚，结束后删除该测试库，不选择业务数据库。
