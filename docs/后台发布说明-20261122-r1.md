# 后台发布说明：2026-11-22 r1

发布包：`luxiaoming-admin-linux-20261122-updater-r1.tar.gz`，从当前正式后台工作区 `luxiaoming-admin-交付包` 生成。包含当前已保存的源码及未提交改动。本次补齐总工作台部署文档的打包白名单。

## 总工作台

相对 2026-11-19 r2，新包包含独立总工作台入口、统计与分页、确认时间和派单向导、派单记录及转派、摄影师档期提示，以及订单、改期、售后、实物发货等原有能力的接入。新入口按原角色与数据范围鉴权，并对列表、详情和共享工具中的客户信息脱敏。

本功能不增加业务表结构。已有权限数据库需要安装 `svcGeneralWorkbench` 菜单，先查看计划，再由部署人员在目标环境按需执行：

```bash
node scripts/install-general-workbench-menu.cjs
node scripts/install-general-workbench-menu.cjs --apply
```

已有开发记录表明，当前项目配置的数据库已于 2026-11-22 安装该菜单；其他服务器仍需核对各自数据库。此次打包未连接数据库或执行安装。安装器不会覆盖已存在菜单的状态及既有授权，详细行为见[总工作台开发与验收](总工作台开发与验收-20261120.md)。

## 企微直接联系配置

新总工作台的企微直接联系默认关闭。启用需要独立的 `WECOM_GENERAL_CONTACT_*` 环境配置、已验证的可信域名、客服企微成员映射和客户外部联系人映射，并在企业微信客户端使用。员工通讯录自动邀请的配置不能替代这些条件。

本地测试通过不代表生产企微通路已联通；部署配置和客户端联调要求见[总工作台企微联系接入](总工作台企微联系接入-20261120.md)。真实配置保存在部署服务器，本包不携带 `.env`。

## 从较旧版本升级

沿用 2026-11-19 r2 的客服企微字段要求：若目标数据库尚未完成专用迁移，应先备份，再使用本包的 `scripts/migrate-wecom-contacts.cjs --apply` 补齐字段。已经完成的数据库无需为总工作台重复执行迁移。通用更新器的 `--migrate` 不能替代该专用迁移。旧版升级步骤见[2026-11-19 r2 发布说明](后台发布说明-20261119-r2.md)，其中包名和临时解压路径替换为本次版本。

## 上传、校验和更新

在本地包所在目录上传：

```bash
scp luxiaoming-admin-linux-20261122-updater-r1.tar.gz luxiaoming-admin-linux-20261122-updater-r1.tar.gz.sha256 用户名@服务器IP:/tmp/
```

```bash
cd /tmp
sha256sum -c luxiaoming-admin-linux-20261122-updater-r1.tar.gz.sha256
sudo bash /opt/luxiaoming-admin/deploy/linux/update.sh /tmp/luxiaoming-admin-linux-20261122-updater-r1.tar.gz
```

部署包不包含 `.env`、`node_modules`、测试目录、业务数据、数据库备份和本机密钥。部署脚本使用 LF 换行和 `0755` 权限，包含更新器及其 helper。此次仅生成和校验本地后台发布包，未上传、部署、迁移或重启服务。
