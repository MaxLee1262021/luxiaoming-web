# 首页与探索商品展示范围

日期：2026-11-08。修改保存在源码，尚未发布。

## 最终展示行为

按确认后的要求，首页不展示照片留影、视频摄像、旅拍套餐或影像周边商品卡片，也不显示商品加载提示及商品为空时的约拍卡片。首页保留轮播、搜索、特色入口、打卡点热榜和热榜横滑分页。

点击热榜打卡点进入共享打卡点详情；默认第一点和后续分页的点位均可点击，保留商家与场景来源，并防止快速重复导航。探索详情继续展示四类已上架商品；旅拍灵感保留关联商品及预约同款入口。只有影像周边的点位也能展示周边，保留详情约拍定制入口。

详情页通常复用前 100 个点位；目标不在已加载目录时才按 ID 精确补查，避免第 101 名以后的热榜入口报点位不存在。精确查询仍检查公开状态和城市条件，过期或卸载后的响应不会覆盖页面。

## 请求与性能

首页请求 getHomeData 时传 includeSpotProducts:false，服务端不再为该请求构建完整点位商品目录。首页不再调用 spotProductsOnly 或逐本 getPhotoCollection。常规目录仍供搜索建议使用，搜索不会因为移除卡片而丢失内容。

继续保留普通冷启动直接进入首页、首张轮播图立即加载、搜索与首页并行读取、隐藏页停止热词轮播、请求内查询复用及 MySQL 独立关系表并行读取等优化。返回首页仍刷新后台最新内容，并恢复已加载的热榜窗口。

服务端保留现有按点商品接口的兼容能力，默认参数行为不变；显式 includeSpotProducts:false 才省略内嵌目录。点位窗口之外的旧相册不会再因隐藏的点位货架触发额外样片读取。显式按点商品接口继续执行公开状态、城市和关联商品可见性检查。

## 验证与发布

验证覆盖首页无商品卡片及额外详情请求、首点与分页点位跳转、来源保留、连点保护、热榜分页与刷新、探索四类商品、仅周边点位、灵感预约同款，以及关闭聚合后的样片读取优化。前后端串联隔离数据包含 25 个点位和超过 100 个商品。

另以 125 个点位的真实 RPC 隔离测试验证详情精确补查、隐藏点位、请求失败重试和旧响应保护；后台相关 47 项回归以及精确查询/热榜 20 项回归通过，后台 119 个模块语法与项目结构构建检查通过。

最终小程序全套 133 项测试全部通过，111 个 JavaScript 文件语法检查通过。

本次无需数据库结构变更。上线需更新后台与小程序；尚未在微信真机或线上部署环境验收。
